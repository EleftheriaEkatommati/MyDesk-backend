# MyDesk Backend Documentation

This documentation set explains the MyDesk backend architecture, deployment strategy, API endpoints, authentication systems, database design, and UI integration.

Files:

- `architecture.md` — technology stack, design decisions, schema, and admin role behavior
- `deployment.md` — running locally, Docker Compose, migrations, and database change workflow
- `api.md` — endpoint reference grouped by category
- `auth.md` — local authentication, JWT, Google OAuth flow, and admin authorization
- `ui-integration.md` — frontend connectivity, CORS, and token delivery
