# MyDesk Backend

This is the backend service for MyDesk, a hot-desking application. It is built with FastAPI and provides a RESTful API for user authentication, desk booking, and administration.

## Tech Stack

- **Framework**: [FastAPI](https://fastapi.tiangolo.com/)
- **Database**: [PostgreSQL](https://www.postgresql.org/)
- **ORM**: [SQLAlchemy](https://www.sqlalchemy.org/)
- **Database Migrations**: [Alembic](https://alembic.sqlalchemy.org/en/latest/)
- **Authentication**: JWT (JSON Web Tokens)
- **Dependency Management**: [Poetry](https://python-poetry.org/)

## Features

- User registration and login with JWT-based authentication.
- Role-based access control (Admin vs. User).
- CRUD operations for users (Admin only).
- List desks and floors.
- Book and cancel desk reservations.

## Getting Started

Follow these instructions to get the project up and running on your local machine for development and testing.

### Prerequisites

- Python 3.10+
- Poetry for dependency management
- PostgreSQL server running

### Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone <your-repository-url>
    cd MyDesk-backend
    ```

2.  **Create and configure the environment file:**

    Copy the example environment file and update it with your database credentials and a new secret key.

    ```bash
    cp .env.example .env
    ```

    Your `.env` file should look like this:
    ```
    DATABASE_URL=postgresql://<user>:<password>@<host>:<port>/<db_name>
    SECRET_KEY=a_very_strong_and_long_random_secret_key
    ALGORITHM=HS256
    ACCESS_TOKEN_EXPIRE_MINUTES=30
    ```

3.  **Install dependencies:**

    Use Poetry to install the project dependencies from the `poetry.lock` file.
    ```bash
    poetry install
    ```

4.  **Run database migrations:**

    Apply the latest database schema using Alembic.
    ```bash
    poetry run alembic upgrade head
    ```

5.  **Seed the database:**

    Populate the database with initial data (roles, admin user, floors). This script depends on a `dummy_data.json` file. Make sure it exists and is configured correctly.
    ```bash
    poetry run python seed_db.py
    ```

6.  **Run the application:**

    Start the FastAPI server with Uvicorn. The `--reload` flag will automatically restart the server on code changes.
    ```bash
    poetry run uvicorn main:app --reload
    ```
    The API will be available at `http://127.0.0.1:8000`.

## Database Migrations (Alembic)

Alembic is used to manage database schema changes.

#### Creating a new migration

After making changes to your SQLAlchemy models in the `models/` directory, generate a new migration script:
```bash
poetry run alembic revision --autogenerate -m "A descriptive message for the change"
```

#### Applying migrations

To apply all pending migrations to your database:
```bash
poetry run alembic upgrade head
```

## API Documentation

The API documentation is automatically generated by FastAPI and is available at:

- **Swagger UI**: `http://127.0.0.1:8000/docs`
- **ReDoc**: `http://127.0.0.1:8000/redoc`

You can also import the `MyDesk-backend.postman_collection.json` file into Postman to have a ready-to-use collection for testing the endpoints.

### Endpoint Summary

#### Auth (`/api/v1/auth`)
| Method | Endpoint | Description | Auth |
|---|---|---|---|
| `POST` | `/register` | Creates a new standard user account. | None |
| `POST` | `/login` | Authenticates a user and returns a JWT. | None |
| `GET` | `/me` | Retrieves the profile of the current user. | User |
| `GET` | `/me/profile` | Retrieves the profile of the current user (id, name, email). | User |

#### Admin (`/api/v1/admin`)
| Method | Endpoint | Description | Auth |
|---|---|---|---|
| `POST` | `/users` | Creates a new user. | Admin |
| `PUT` | `/users/{user_id}/role` | Updates the role of a specific user. | Admin |
| `GET` | `/users` | Retrieves a list of all users. | Admin |

#### Desks & Floors (`/api/v1/desks`)
| Method | Endpoint | Description | Auth |
|---|---|---|---|
| `GET` | `/` | Retrieves a list of all desks with booking status for a given date (`?date=YYYY-MM-DD`). | None |
| `GET` | `/floors` | Retrieves a list of all floors. | None |
| `GET` | `/floors/{floor_id}` | Retrieves metadata for a single floor. | None |
| `POST` | `/{desk_id}/book` | Books a desk for the current user. | User |
| `GET` | `/floors/{floor_id}/desks` | Retrieves desks for a floor with booking status for a given date (`?booking_date=YYYY-MM-DD`). | None |

#### Bookings (`/api/v1/bookings`)
| Method | Endpoint | Description | Auth |
|---|---|---|---|
| `GET` | `/me` | Retrieves all bookings for the current user. | User |
| `PUT` | `/{booking_id}/cancel` | Cancels a booking for the current user. | User |
